# 体調記録システム（脳脊髄液減少症／良性発作性頭位めまい症）

スマホ（LINE）から選択式で体調を記録し、
- 決まった時刻（朝8時・昼13時・夜21時）に **本人へLINEでリマインド**
- 1日1回（22時）**家族へLINEでまとめ通知**、悪化時（強い頭痛・転倒・危険なサイン）は **即時通知**
- 医師向けに **A4レポート（印刷・PDF保存）と CSV** を出力

する仕組みです。

```
 本人/家族のLINE ──(リッチメニュー/通知ボタン)──▶ LIFF画面（GitHub Pages: docs/）
                                                     │  記録・閲覧（IDトークン付き）
                                                     ▼
 LINE公式アカウント ◀──プッシュ通知── Google Apps Script（gas/Code.gs）──▶ Googleスプレッドシート（記録の保存先）
                                        ↑ 10分ごとの時間主導トリガー（リマインド・まとめ）
```

| 場所 | 内容 |
|---|---|
| `docs/` | スマホ画面（GitHub Pagesで公開）。`fields.js` が記録項目の定義 |
| `docs/report.html` | 医師用A4レポート・CSV出力 |
| `gas/Code.gs` | バックエンド（API・LINE通知・定時処理） |

> **デモ**：`config.js` 未設定のまま GitHub Pages の URL を開くとサンプルデータで画面を確認できます（`?role=family` で家族画面）。

## セットアップ手順（所要 30〜40分）

### 1. GitHub Pages を有効化
1. このリポジトリの **Settings → Pages**
2. Source: `Deploy from a branch`、Branch: `main` / フォルダ `/docs` → Save
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` が公開URLになります（以下「PagesのURL」）

### 2. スプレッドシートと GAS を用意
1. Googleドライブで新しいスプレッドシートを作成（例：「体調記録」）
2. メニュー **拡張機能 → Apps Script** を開く
3. `Code.gs` の中身を全部消し、このリポジトリの `gas/Code.gs` を貼り付けて保存
4. 左の「プロジェクトの設定」→「appsscript.json マニフェストを表示」をON → `appsscript.json` を `gas/appsscript.json` の内容に置き換え
5. 関数 `setup` を選んで **実行**（初回は権限の承認が出ます）
   - 実行ログに **本人用・家族用の合言葉** が表示されます（シート「設定」にも記載）

### 3. LINE の準備（[LINE Developers](https://developers.line.biz/console/)）
1. プロバイダーを作成
2. **Messaging API チャネル** を作成（＝LINE公式アカウント）
   - 「Messaging API設定」→ **チャネルアクセストークン（長期）** を発行してコピー
   - LINE Official Account Manager で「応答メッセージ」をオフ、「Webhook」をオン
3. 同じプロバイダーに **LINEログイン チャネル** を作成
   - 「チャネル基本設定」の **チャネルID** をコピー
   - 「リンクされたLINE公式アカウント」に上の公式アカウントを設定（友だち追加の案内が出ます）
   - 「LIFF」タブ → 追加：サイズ `Full`、エンドポイントURL＝**PagesのURL**、Scope `openid` `profile` にチェック、友だち追加オプション `On (Aggressive)`
   - 作成された **LIFF ID** と **LIFF URL（https://liff.line.me/…）** を控える

### 4. GAS に値を設定してデプロイ
1. Apps Script「プロジェクトの設定」→ **スクリプト プロパティ** に追加
   - `LINE_CHANNEL_ACCESS_TOKEN` … 3-2 のトークン
   - `LINE_LOGIN_CHANNEL_ID` … 3-3 のチャネルID
2. スプレッドシートのシート「設定」で `APP_URL` に **LIFF URL**、`PATIENT_NAME` に呼び名を入力
3. Apps Script 右上 **デプロイ → 新しいデプロイ → 種類：ウェブアプリ**
   - 実行ユーザー：自分／アクセスできるユーザー：**全員** → デプロイ
   - 表示された **ウェブアプリURL（…/exec）** をコピー
4. LINE Developers の Messaging API設定 → **Webhook URL** に上記URLを入力し「Webhookの利用」をON
   （「検証」ボタンで 302 エラーと表示されることがありますが、GASの仕様によるもので実際の受信は問題ありません）

> コードを修正したら「デプロイを管理 → 編集 → バージョン：新バージョン」で更新（URLは変わりません）。

### 5. 画面側の設定
`docs/config.js` を GitHub 上で編集（鉛筆アイコン）して保存：
```js
LIFF_ID: "2001234567-AbCdEfGh",
GAS_URL: "https://script.google.com/macros/s/xxxxxxxx/exec",
```

### 6. リッチメニュー（任意・推奨）
LINE Official Account Manager → リッチメニュー で、ボタンのリンクに
- 記録する：`<LIFF URL>?view=record`
- 履歴・グラフ：`<LIFF URL>?view=history`
- 医師用レポート：`<LIFF URL>/report.html`

### 7. 登録
1. 本人・家族それぞれが公式アカウントを **友だち追加**
2. 届いたメッセージのボタン（またはリッチメニュー）から画面を開き、**合言葉**を入力
   - 本人：`P-` で始まる合言葉 → 記録できる
   - 家族：`F-` で始まる合言葉 → 閲覧と通知の受け取りのみ
3. Apps Script で `testReminder` / `testFamilySummaryToday` を実行すると通知を試せます

## 使い方

- **記録**：時間帯（朝・昼・夜）を選び、ボタンを押していくだけ。必須は「体調」と「頭痛の強さ」のみ。
  「前回と同じ」で直前の記録をコピーして、違う所だけ直せます。昨日・おとといの分も後から記録可。
- **夜だけ**「1日のふりかえり」（起きて過ごせた時間・水分・薬・処置・天気・気分）が出ます。
- **危険なサイン** を選ぶと受診の案内（#7119／119）が表示され、家族へ即時通知されます。
- **医師用**：期間を選び「印刷・PDF保存」→ 送信先「PDFに保存」で A4 のPDFに。CSV も同じ画面から。
  LINEの中では印刷・ダウンロードできないことがあるため「ブラウザで開く」を押してから操作してください。

## 設定（スプレッドシート「設定」シート）

| 項目 | 既定値 | 説明 |
|---|---|---|
| REMIND_TIMES | 08:00,13:00,21:00 | リマインド時刻（その時間帯が未記録の場合のみ送信） |
| RENOTIFY_MINUTES | 0 | 未記録時の再通知（例：90）。0でなし |
| FAMILY_SUMMARY_TIME | 22:00 | 家族への1日まとめ時刻 |
| ALERT_HEADACHE | 8 | この値以上の頭痛で家族へ即時通知 |
| LATITUDE / LONGITUDE | 東京 | 記録時の気圧を自動取得する地点（空欄で無効） |

※時刻はセルの書式を「書式なしテキスト」にしておくと安全です。

## メッセージ通数の目安（重要）

LINE公式アカウントの無料プランは **月200通**（プッシュ通知の通数。返信は含まない）です。
- 本人リマインド：3回×30日 ＝ 約90通
- 家族まとめ：1回×30日×家族人数（2人なら60通）
- 悪化時の即時通知：その都度×家族人数

再通知（RENOTIFY_MINUTES）をONにすると200通を超えやすくなります。足りない場合は有料プランを検討してください。
送信結果はシート「送信ログ」で確認できます。

## 記録項目を変えたいとき
`docs/fields.js` を編集するだけで、入力画面・CSV・レポートに反映されます（スプレッドシートの列も自動追加）。

## セキュリティ・プライバシー
- 記録データは **自分のGoogleスプレッドシートにのみ** 保存され、GitHubには保存されません。
- 画面のAPIは LINEログインの IDトークンをサーバー側で検証し、合言葉で登録済みのユーザーだけが読み書きできます。
- スプレッドシートは共有しないでください。合言葉が漏れた場合は「設定」シートで変更し、「ユーザー」シートの不要な行の「有効」を FALSE にしてください。
- GitHub Pages で公開するためリポジトリは公開（Public）になりますが、含まれるのは画面のプログラムのみです。

## 記録項目の考え方
- **脳脊髄液減少症**：起立性頭痛（立位・座位で悪化し、臥位で軽快）が中心症状。悪化までの時間、横になって楽になるか、起きて過ごせた時間、首の痛み・耳鳴り・耳閉感・吐き気・羞明・倦怠感・集中困難などの随伴症状、水分摂取、ブラッドパッチ等の処置、気圧の変化を記録。
- **良性発作性頭位めまい症**：寝返り・起き上がり・上を向くなど頭の位置の変化で起こる、短時間（多くは1分以内）の回転性めまい。種類・回数・長さ・きっかけ（左右の寝返りを区別）・強さ・ふらつき/転倒を記録。
- **食事**：時間帯ごとに食べられた量（しっかり／半分／少し／食べられず）と、食べたもの（主食・たんぱく質・野菜・汁物など）、食べられなかった理由を選択。レポートの日別一覧では ◎○△× で表示。
- **活動**：前回の記録から今までの 徒歩／ストレッチ施術／立位での事務／座位での事務 の時間（分）を選択し、その他は自由記入。起立負荷と症状の関係を医師が確認しやすくするため、立位と座位を分けています。
- 本システムは記録の補助であり、診断や治療の判断は必ず医師にご相談ください。
